# Code of Conduct

## Our standard

AegisX exists to help people, including vulnerable ones, stay safer online. The same standard applies to
how people treat each other around this project.

Participants are expected to:

- Be respectful and constructive, especially when disagreeing about a technical or design decision.
- Welcome contributors regardless of experience level — a hackathon project should be a reasonable place
  for a first-time contributor to learn, not just a venue for experts.
- Give and accept feedback gracefully. Use [`docs/adr/`](./docs/adr/0000-index.md) to make the *reasoning*
  behind a decision explicit, which reduces unproductive disagreement over something already settled for
  a stated reason.
- Avoid harassment, discriminatory language or jokes, and personal attacks, in issues, pull requests,
  commit messages, and any other project space.

## Reporting

If you experience or witness unacceptable behaviour, report it using the contact method in
[`SECURITY.md`](./SECURITY.md) (the same channel, kept simple for a project this size). Reports will be
handled with discretion.

## Scope

Applies within all project spaces (repository, issues, pull requests) and when representing the project
publicly.
